KEY INSIGHT

응답에서 음악·연주와 영상·엔터테인먼트 관련 취미가 두드러진다. 개인별 취향은 다르지만, 음악을 듣거나 직접 연주하고 다양한 콘텐츠를 소비하는 활동이 주요 관심사로 나타난다.

분석 기준: 취미 항목은 원문 응답을 키워드 기준으로 재분류했으며, 한 응답에 여러 관심사가 포함될 수 있어 합계가 전체 응답자 수와 일치하지 않을 수 있음. 성별·주소·이름·개인 계정 및 ‘가장 아끼는 것’의 개별 응답은 개인정보 보호를 위해 시각화에서 제외함. GitHub Pages 수치는 주소가 입력된 행을 기준으로 집계.
